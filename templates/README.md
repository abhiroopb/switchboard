# Templates

Blank starting points for recurring PM documents.

## Current templates

- PRD, roadmap, status update, meeting notes
- decision records and architecture docs
- launch checklists and release plans
- research, retrospectives, and OKRs
- prototype lifecycle: `prototype-discovery-template.md` (the gate doc), `prototype-research-template.md`, `prototype-changelog-template.md`, `prototype-demo-template.md`, `prototype-decision-template.md`. `python3 .agents/skills/building-prototypes/scripts/prototype.py init <slug>` renders them into a prototype folder; see the `building-prototypes` skill.
- Obsidian core Templates (this folder is the configured template folder): `daily-note-template.md` (auto-applied to `notes/daily/` by the Daily notes plugin) and `review-note-template.md` (start point for `outputs/reviews/` notes; `{{title}}` and `{{date}}` are filled by Obsidian)

Prefer starting here before creating a brand-new document shape.

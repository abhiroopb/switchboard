# PM OS Home

This vault is the PM OS repository opened in place. Every file below lives where it always has; Obsidian only reads it. Start here, then use the file explorer or Quick Switcher (⌘O) to jump anywhere.

New to the vault? Read [Obsidian onboarding](docs/obsidian-onboarding.md) first.

## Review queue

- [Reviews for {{OWNER_FIRST}}](outputs/reviews/INDEX.md) — new review notes land here (one Markdown note per deliverable, newest first). Each note carries `status: to review` in its frontmatter until you clear it.
- [Command center snapshot](system/state/command-center-latest.md) — the ranked queue the start-of-day routine renders (regenerated; local-only).

## Conventions in this vault

- Links are plain relative Markdown links, not wikilinks, so they resolve in GitHub, editors, and Obsidian alike.
- Frontmatter uses `title`, `date`, `status`, `workstream`, `task_id`, `sources`; the Properties panel renders it.
- Obsidian Sync, Publish, and community plugins stay off. Core plugins only.
- `system/state/`, `.amp/`, logs, and caches are hidden from the explorer via `.obsidian/app.json` `userIgnoreFilters`; they still exist on disk.
- `INDEX.md` files are generated by `python3 system/scripts/build-vault-indexes.py --write` (`--check` reports drift). Edit the script, not the files. `README.md` files are hand-written and stay authoritative for purpose and conventions.

## Excluded technical paths and formats

These exist in the repo but are hidden from the explorer or do not render in Obsidian. Nothing was moved or deleted; they simply are not documentation.

- Runtime state and logs: `system/state/`, `system/logs/`, `system/recall/`, `.state/`, `.amp/`, `.claude/`, `.config-mirror/`, `.firecrawl/`, `.ruff_cache/`. Read-only mirrors of JSON/queues that scripts rebuild.
- Comms-triage temp files (`outputs/comms-triage/**/.comms-*`, `outputs/.pending-comms.*`): mktemp leftovers from `daemon/comms-prompt.sh`; hidden via regex filters and gitignored.
- Code and config: `system/scripts/*.py`, `system/amp-plugins/*.ts`, `daemon/*.sh`, `*.yaml`, `*.json`. Open these in an editor; Obsidian shows them as unsupported files. The [system index](system/INDEX.md) lists only the Markdown inside `system/`.
- HTML deliverables: `outputs/presentations/*/index.html`. Obsidian cannot render HTML; open the deployed site URL or the file in a browser. Images (`.png`, `.jpg`, `.svg`) render inline.
- People profiles and sensitive notes (`people/`, `notes/sensitive/`) are visible in the vault but never pushed; keep them local.
